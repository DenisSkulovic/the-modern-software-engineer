# Engineering assignment

Start with `react-interview-lab-01/INTERVIEW_BRIEF.md` when you are ready. The same standalone application is supplied as `react-interview-lab-01.zip`.

Copy the candidate folder outside this study repository, or extract the ZIP. For a fresh local baseline:

```sh
git init
git add .
git commit -m "Initial application"
npm ci
npm run dev
```

Run these commands inside the candidate application. Its README contains the environment and verification commands.

**DO NOT OPEN `react-interview-lab-01-instructor/` before or while taking the exam.** It is for the examining assistant and the separate review. It is excluded from the candidate application and ZIP.
