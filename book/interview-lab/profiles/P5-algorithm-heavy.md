# P5 — Algorithm-heavy technical assessment

**Status:** **opt-in** or evidence-driven  
**Use when:** The candidate explicitly asks, or the employer / invitation strongly indicates DSA rounds.

## Snapshot

| Field | Default |
| --- | --- |
| Focus | Data structures, algorithms, complexity, unfamiliar problems under time pressure |
| Primary curriculum reference | `CS360` |
| Default for generic FS roles | **No** |

## Rules

- Do not select P5 merely because online prep culture is algorithm-heavy.
- Prefer practical coding (API, async bug, SQL, small feature) unless P5 is justified.
- Even under P5: evaluate clarification, tests, complexity reasoning — not only “got the trick.”
- Do not arbitrarily jump to advanced graph / DP for a role that never mentioned them.
