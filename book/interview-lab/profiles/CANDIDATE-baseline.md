# Candidate baseline

Living assumptions for Interview Lab simulations. Update this file when reality changes. Do not invent facts that are not listed here.

## Seniority calibration

- Experienced **mid-level to senior** full-stack engineer with substantial backend exposure.
- Calibrate to the **actual job**, not to Staff/Principal by default.
- Do not assume expert depth in every tool named on a JD.

## Stack (working familiarity unless noted)

- **Languages / runtimes:** JavaScript, TypeScript, Node.js; Python services and async work.
- **Frontend:** Vue deeper; React used in jobs/interviews but independent React reasoning is a known weakness — study path `SE250` (stubs → manuscripts). Do not assume React hook mastery in mocks unless SE250 progress or the user says otherwise.
- **Data:** PostgreSQL, MongoDB; Redis; messaging and background jobs.
- **Delivery / ops:** Docker, Kubernetes, cloud, CI/CD, production debugging.
- **Systems topics:** API architecture, business workflows, integrations, observability, maintenance.

## Target markets (primary)

Prepare for **European product-engineering roles**, especially:

- Germany (and broader DACH when relevant)
- Netherlands
- Sweden (and similar Nordics when relevant)
- Comparable EU / EEA product companies and Europe-based international teams
