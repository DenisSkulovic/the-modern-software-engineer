# P2 — Backend-heavy product or cybersecurity company

**Status:** reusable preset  
**Use when:** Role emphasizes services, workers, data stores, infra, integrations, or security-adjacent backends.

## Snapshot

| Field | Default |
| --- | --- |
| Market | Europe by default (DE / NL / SE or similar), or as stated in the JD |
| Company type | Product company; may be cybersecurity-adjacent |
| Role | Backend or full-stack with heavy service ownership |
| Seniority | Mid → senior |
| Algorithm-heavy | Only with evidence |

## Prioritize

- Correctness under failure; async workflows
- Python and/or Node.js service behavior
- MongoDB or SQL; queues; scalability; debugging; ownership
- Realistic architecture or code-review scenarios when appropriate

## Typical round shapes

- Deep technical conversation from a real service the candidate owned
- Debugging / incident-style probes
- Code review of a flawed PR
- Focused design around an integration, worker, or multi-tenant API — not generic social-network scale
