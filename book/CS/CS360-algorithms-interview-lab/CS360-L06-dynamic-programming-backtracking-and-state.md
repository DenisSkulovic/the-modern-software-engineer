## Lecture 06: Dynamic Programming, Backtracking, and State

### Learning Objective

Recognize reusable subproblems and construct state representations rather than memorizing recurrence formulas.

### Opening Problem

A search algorithm recomputes the same subproblems thousands of times, while a different problem requires exploring combinations without searching blindly.

### Planned Coverage

Recursive state, memoization, bottom-up dynamic programming, state transitions, overlapping subproblems, optimal substructure, backtracking, pruning, and distinguishing optimization from enumeration.

### Scope Boundaries

Avoid formula memorization. Teach state design and when DP versus backtracking is the right tool.

### Expected Understanding

Define a state and transition; choose memoization or bottom-up DP; prune a backtracking search without losing required solutions.

### Practice Focus

Sequence problems, bounded choices, path counting, constrained combinations, and optimization under limited resources.
