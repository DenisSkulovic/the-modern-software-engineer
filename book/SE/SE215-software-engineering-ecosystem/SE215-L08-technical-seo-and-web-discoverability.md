### Learning Objective

Understand how a technically functioning web application can fail to become discoverable through search engines.

### Opening Problem

A company rebuilds its public hotel catalogue using a modern JavaScript application. The pages look better and load quickly for users, yet organic search traffic begins falling.

### Planned Coverage

Search-engine crawling, rendering, indexing, crawlability, indexability, robots.txt, XML sitemaps, canonical URLs, redirects, HTTP statuses, meta robots directives, page titles and descriptions, structured data, internal linking, duplicate URLs, internationalization and hreflang, mobile usability, performance, Core Web Vitals, and search diagnostics. How CSR, SSR, and static generation affect discoverability. Google Search Console and diagnostic workflows. Distinguish developer-owned technical SEO from content strategy and marketing.

### Scope Boundaries

SE240-L04 already explains rendering strategies and their SEO implications. Preserve that discussion; this lecture owns the broader technical SEO overview.

### Expected Understanding

Diagnose common technical SEO problems and communicate effectively with SEO specialists and product teams.

### Suggested Exercise / Lab

Audit a small public website's indexing directives, metadata, canonical URLs, sitemap, and structured data.
